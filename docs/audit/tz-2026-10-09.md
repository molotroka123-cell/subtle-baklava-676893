## 3. Методика (для каждой записи)

1. Тест **бесплатным стеком**: что работает из коробки, латентность, стабильность.
2. Тест **платным стеком**: что меняется, сколько стоит, оправдано ли.
3. Вердикт строго одним из: `PASS` / `BLOCKED` / `NOT_TESTED` / `DEFERRED`.
4. Если `BLOCKED` по действию Тимура — фиксируется ровно что нужно (ссылка OAuth, ключ, аккаунт), без общих фраз.
5. Запись попадает в список «к внедрению» только с доказанной пользой: конкретный закрытый кейс из его жизни, а не «может пригодиться».

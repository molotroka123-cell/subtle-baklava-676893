# Bossman — витрина развития

Открытая страница на Netlify: живое **дерево развития Bossman**, у каждого узла — **статья**, лента изменений из git, лестница самоулучшения (North Star) и файлы для ИИ. Страница статическая; данные в `data/` обновляет парсер с компьютера владельца.

## Что где
| Путь | Что это |
|---|---|
| `index.html`, `style.css`, `app.js`, `tree-scene.js` | сайт: Canvas-дерево, статья по клику (`#/n/<id>`), поиск (`/` или Ctrl+K), лента, пульс, анимации (уважает `prefers-reduced-motion`) |
| `data/meta.json`, `tree.json`, `timeline.json`, `articles/<зона>.json` | снимок развития (генерируется) |
| `ai/bossman-development.md`, `llms.txt` | всё развитие одним текстом для ИИ |
| `scripts/sync_bossman.py` | **парсер**: репозиторий Bossman → данные витрины |
| `scripts/sync_from_pc.cmd` | то же двойным кликом на Windows (+ git push) |
| `data/hide.txt` | темы, которые никогда не показываются публично |
| `tests/` | тесты парсера (`python -m unittest discover -s tests`) и браузерная проверка (`python tests/e2e_site.py`) |

## Обновить данные с компьютера
```
python scripts\sync_bossman.py --source C:\путь\к\AiMaxBossman            # снимок из git и кода
python scripts\sync_bossman.py --source ... --live auto                   # + живые счётчики с запущенного Bossman
python scripts\sync_bossman.py --source ... --push                        # + commit/push (Netlify соберёт сайт сам)
python scripts\sync_bossman.py --source ... --enrich                      # + «простыми словами» бесплатной моделью (нужен ключ OpenRouter)
```
Парсер использует только стандартную библиотеку Python и git. **Ключи и платные модели не нужны ($0).**

## Что собирается и откуда
* **Дерево и статусы** — `command-center/bcc/capability_tree_seed.json` (та же карта, что в локальном интерфейсе).
* **Статья узла** — из того, что реально лежит в коде/доках: описание модуля (docstring/README), основные функции, число тестов, которые импортируют модуль, история изменений файла из git, уровень доказательства и следующий шаг. Это не пересказ ИИ.
* **«Простыми словами»** — только если запустить `--enrich`: бесплатная модель (id заканчивается на `:free`, платные отклоняются), по фактам из статьи, с кэшем и лимитом запросов. Раздел помечается как пересказ моделью. Без ключа шаг честно пропускается.
* **Лента** — `git log` (без merge-коммитов, дубликаты склеены), заголовки как написали разработчики.
* **Живые счётчики самоулучшения** — только с `--live` у запущенного Bossman (тот же клиент и токен, что у CLI/дашборда). Личные заметки владельца и id задач не экспортируются.

## Публичность и безопасность (fail-closed)
* Вырезаются: локальные пути (Windows/UNC/`%VAR%`/`~`/`/home/…`), адреса localhost и LAN, e-mail, токены и ключи, пути файлов репозитория в тексте, ссылки на приватный репозиторий.
* После генерации **весь вывод проверяется ещё раз**; при любой находке данные **не записываются** (код выхода 3, `SYNC=LEAK_BLOCKED`).
* Файлы с именами `.env`, `*secret*`, `*vault*`, `*credential*`, `*.pem`, `*.key`, а также симлинки наружу и `..` не читаются.
* `--no-code-details` — минимум раскрытия: только карта, без чтения кода и документов.
* Показываются имена публичных функций и фрагменты описаний из кода, а также заголовки коммитов. Если это лишнее — используйте `--no-code-details` и/или добавьте слова в `data/hide.txt`.

## Честность карты
Цвет листа — **уровень доказательства**, а не PASS: «код написан» ≠ «работает»; «Работает в Bossman» — тесты листа прошли против кода установленной сборки на указанном коммите (отчёт о прогоне, не PASS релиза). Лестница North Star показывает достигнутым только `SELF_IMPROVEMENT_INFRASTRUCTURE_PRESENT`; остальное «не доказано», пока не появится проверка на точном коммите (правится в `data/ladder.override.json`: `{"reached": [...]}`).
Витрина — ещё одна поверхность наблюдения за **тем же** Bossman: она ничего не запускает, не меняет и не имеет доступа к его данным.
